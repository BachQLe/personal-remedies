Primary CTA button for Personal Remedies. Use for the main action on any screen.

```jsx
<PrimaryButton size="md" onClick={handleNext}>See my daily picks</PrimaryButton>
<PrimaryButton size="lg" fullWidth>Continue setup</PrimaryButton>
<PrimaryButton disabled>Not available</PrimaryButton>
```

Variants: sm (40px), md (52px default), lg (60px). The corner bracket accent (top-right) is always shown.
Background: --forest-700. Text: --text-on-dark. Radius: --radius-xs (6px).
