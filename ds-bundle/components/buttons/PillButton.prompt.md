Rounded pill button with 4 variants. Use for inline actions, filter pills, and nav chips.

```jsx
<PillButton variant="forest">See all foods</PillButton>
<PillButton variant="accent">Highlight</PillButton>
<PillButton variant="ghost">Skip</PillButton>
<div style={{background:'var(--blue-950)',padding:16}}>
  <PillButton variant="ghost-dark">Cancel</PillButton>
</div>
```
